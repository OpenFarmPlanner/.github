# Security Policy

Thank you for helping keep OpenFarmPlanner and its users safe.

## Reporting a vulnerability

**Please do not report security problems through public issues, discussions
or pull requests.**

- **Preferred:** use GitHub's private vulnerability reporting: open the
  affected repository's **Security** tab and click **Report a vulnerability**.
- **Alternative:** email [info@openfarmplanner.org](mailto:info@openfarmplanner.org).

Please include:

- the affected repository, URL or API endpoint,
- steps to reproduce,
- the impact you expect (what an attacker could do),
- any proof of concept you have.

## What to expect

- We acknowledge your report within **7 days**.
- We then assess it and tell you the planned timeline for a fix.
- Once fixed, we publish a GitHub Security Advisory. If you wish, we credit
  you in it.

OpenFarmPlanner is a solo-maintained open-source project. Please be patient
with response times. There is no bug bounty.

## Scope

**In scope**

- Code in all repositories of the
  [OpenFarmPlanner](https://github.com/OpenFarmPlanner) organization.
- The hosted instance at [openfarmplanner.org](https://openfarmplanner.org).

Only the latest release and the `main` branch are supported.

**Out of scope**

- Denial-of-service attacks or load testing against the live instance.
- Social engineering, phishing and physical attacks.
- Spam.
- Attacks on other users' accounts or data.
- Findings in third-party services we use. Please report those to the
  respective vendor.

When testing the live instance, use only your own test accounts. Never
access, modify or delete other users' data.

## Safe harbor

We will not take legal action against good-faith security research that
follows this policy. If you come across real user data, stop right there and
report what you found. Do not access or keep more of it.
